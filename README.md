Palm Bay Heat is a Leonida cover studio: a static web app that turns your own photos and a caption into multi-panel GTA-style cover art — graded photos set in a panel grid beside drawn sunset and neon art panels, finished with bold poster lettering — and exports a share-ready PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. It runs fully offline from the files under app/, and your photos never leave your machine.

## Run it

```sh
python3 -m http.server 8080 --directory app
# then open http://localhost:8080 in a desktop browser
```
